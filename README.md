# 🇰🇿 Telegram-бот «Путеводитель по сакральным местам Павлодарской области»

Современный Telegram-бот для изучения сакральных мест Павлодарской области в рамках программы «Рухани жаңғыру».

## ✨ Возможности

### Основные функции
- 📱 **7 объектов** республиканского значения с подробными описаниями
- 📸 **Фотогалереи** каждого объекта
- 🗺 **Интеграция с картами** — прямые ссылки на Google Maps
- 📖 **Историческая информация** о каждом месте

### Современные функции
- ⭐️ **Избранное** — сохраняйте интересные объекты
- 🔍 **Поиск** — находите объекты по названию и описанию
- 📤 **Inline-режим** — делитесь информацией в любом чате
- 📊 **Статистика** — отслеживайте свои просмотры
- ❤️ **Реакции** — добавляйте/удаляйте из избранного одним нажатием

## 🚀 Установка и запуск

### 1. Клонируйте репозиторий
```bash
git clone <repository-url>
cd Telegram-bot-pvl2
```

### 2. Создайте виртуальное окружение
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

### 3. Установите зависимости
```bash
pip install -r requirements.txt
```

### 4. Настройте переменные окружения
Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

Откройте `.env` и добавьте токен вашего бота от [@BotFather](https://t.me/BotFather):
```
BOT_TOKEN=your_bot_token_here
```

### 5. Убедитесь, что папка `photos/` содержит изображения
Структура должна быть такой:
```
Telegram-bot-pvl2/
├── bot2.py
├── photos/
│   ├── мш1.jpg
│   ├── мш2.jpg
│   └── ...
├── .env
└── requirements.txt
```

### 6. Запустите бота
```bash
python bot2.py
```

## 🎯 Использование

### Команды бота
- `/start` — главное меню
- `/help` — справка по командам
- `/search` — поиск объектов
- `/favorites` — избранные объекты
- `/stats` — ваша статистика

### Inline-режим
Напишите `@your_bot_name` в любом чате, чтобы поделиться информацией об объектах с друзьями.
